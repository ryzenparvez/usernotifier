# JSN WiFi বিল নোটিশ পপ-আপ

## কীভাবে কাজ করে
1. `data/` ফোল্ডারের পেমেন্ট CSV থেকে প্রতিটি ইউজারের সর্বশেষ পেমেন্ট তারিখ নেয়; পরের মেয়াদ = পরের মাসের একই তারিখ।
2. প্রতি ৬০ সেকেন্ডে MikroTik-এর `/ppp active` থেকে ইউজারের বর্তমান IP নেয়।
3. মেয়াদের ৩ দিন আগে থেকে IP যায় `bill-warn` লিস্টে, মেয়াদ শেষে `bill-expired` লিস্টে।
4. MikroTik ওই IP-র HTTP ট্রাফিক আপনার PC-র পপ-আপ সার্ভারে পাঠায়। ফোন/PC নিজে থেকেই captive-portal চেক করে পপ-আপ দেখায়।
5. সতর্কতার পপ-আপে "বুঝেছি" চাপলে ৩ ঘণ্টা আর আসবে না (`seen_timeout`)। মেয়াদ শেষ হলে পপ-আপ থাকবেই, বাকি ইন্টারনেট বন্ধ।

## নতুন ডিজাইন (Furqan Cloud থিম)
- `theme.css`/`base.css`: আপনার `styles.css` এর পুরো কালার থিম (লাইট + ডার্ক)। উপরের ডানে লাইট/ডার্ক বাটন; পছন্দ ব্রাউজারে মনে থাকে।
- একটাই পেজে বাঁ দিকে NavBar: ওভারভিউ · অনলাইন ইউজার · সব ইউজার · CSV আপলোড | MikroTik · ডোমেন ও অ্যাক্সেস · কাস্টমাইজ · পপ-আপ ডিজাইন · লগইন ও পাসওয়ার্ড। মোবাইলে এটা উপরের স্ক্রলযোগ্য বার।
- `popup.html`: আপনার ফাইনাল পপ-আপ ডিজাইন (Jashodal Internet লোগো, bKash আইকন, মোবাইলে ১:১ স্কোয়ার)। লোগো, নম্বর, অফিস, ফোন ও লেখা সেটিং > পপ-আপ ডিজাইন থেকে বদলানো যায়।

## লগইন ও ড্যাশবোর্ড
`http://PC-র-IP:8080/admin` এ লগইন পেজ আসবে (ইউজার/পাসওয়ার্ড `auth.json` এ হ্যাশ করে রাখা; আসল পাসওয়ার্ড কোথাও লেখা নেই)। সেশন কুকি, ৫ বার ভুলে ১৫ মিনিট লক। সেটিং পেজে ৫টা ট্যাব: **MikroTik**, **ডোমেন ও অ্যাক্সেস**, **ড্যাশবোর্ড কাস্টমাইজ** (নাম, রং, সতর্কতার দিন, রিফ্রেশ ইত্যাদি), **পপ-আপ কাস্টমাইজ** (bKash নম্বর, প্যাকেজ, যোগাযোগ, লেখা), **লগইন ও পাসওয়ার্ড** (ইউজার/পাসওয়ার্ড বদল + বদলের ইতিহাস)। প্রথম লগইনের পর পাসওয়ার্ড বদলে নিন।

## ডোমেইন দিয়ে যেকোনো জায়গা থেকে অ্যাক্সেস
সফটওয়্যার PC-তেই চলে। সেটিং > ডোমেন ও অ্যাক্সেস এ ডোমেইন, পাবলিক IP, PC-র লোকাল IP দিলে MikroTik রুল ও Caddyfile নিজে তৈরি হয়:
1. DNS-এ A রেকর্ড: ডোমেইন → MikroTik পাবলিক IP।
2. MikroTik-এ পোর্ট 80/443 → PC ফরওয়ার্ড (সেটিং পেজের রুল পেস্ট করুন)।
3. PC-তে Caddy চালান (`Caddyfile.example`); এটা ফ্রি HTTPS সার্টিফিকেট নিজে আনে।
পোর্ট 8080 কখনো ইন্টারনেটে ফরওয়ার্ড করবেন না। পাবলিক IP আসল হতে হবে (CGNAT চলবে না)।

## MikroTik ইন্টিগ্রেশন ও সতর্কবার্তা বাটন
ড্যাশবোর্ডের "⚙ MikroTik ইন্টিগ্রেশন সেটিং" এ পাবলিক IP (বা লোকাল IP), API পোর্ট (8728, SSL হলে 8729), API ইউজার ও পাসওয়ার্ড দিয়ে "সেভ ও কানেকশন টেস্ট" চাপুন; সেটিং `settings.json` এ সেভ হয় (GitHub-এ যায় না)। এরপর "MikroTik অনলাইন ইউজার" তালিকায় প্রতি ইউজারের পাশে **⚠ পপ-আপ পাঠান** বাটন থাকবে। চাপলে ঐ অনলাইন ইউজারের কাছে তাৎক্ষণিক পপ-আপ যায় (৩০ মিনিট চালু থাকে, কাস্টম বার্তাও দেওয়া যায়)। অনলাইন তালিকা প্রতি ১৫ সেকেন্ডে আপডেট হয়।
- শুধু অনলাইন ইউজার দেখতে read অনুমতি যথেষ্ট, কিন্তু পপ-আপ পাঠাতে address-list লিখতে হয় বলে write-ও লাগে।
- API পোর্ট ইন্টারনেটে খুললে `/ip service set api address=সফটওয়্যারের-IP` দিয়ে সীমাবদ্ধ করুন।
- সফটওয়্যার PC-তে না থেকে অন্য সার্ভারে চললে সেই সার্ভারের পাবলিক IP-তে পোর্ট 8080 ক্লায়েন্টদের জন্য খোলা থাকতে হবে।

## সেটআপ (Windows PC)
1. Python ইন্সটল করুন (python.org, "Add to PATH" টিক দিন)।
2. MikroTik-এ `mikrotik_setup.rsc` এর উপরের IP/পাসওয়ার্ড বদলে Terminal-এ পেস্ট করুন। PC-র গেটওয়ে MikroTik হতে হবে, আর PC-র IP স্থির (static) রাখুন।
3. `config.example.ini` কপি করে `config.ini` নাম দিন। রাউটার, ডোমেইন, bKash নম্বর সব এখন ড্যাশবোর্ডের সেটিং থেকে দেওয়া যায়।
4. `start.bat` এ ডাবল-ক্লিক করুন। অটো-স্টার্টের জন্য Task Scheduler-এ বুট/লগ-অনে `start.bat` চালানোর টাস্ক বানান।
5. রাউটার ছাড়া টেস্ট: `py jsn_notifier.py report 2026-08-02`

## জেনে রাখুন
- **HTTPS সাইটের (YouTube/Facebook) ভেতরে জোর করে পপ-আপ বসানো যায় না।** পপ-আপ আসে ফোনের captive-portal নোটিফিকেশন/শিট হিসেবে, আর HTTP সাইট খুললে সরাসরি পেজ হিসেবে। Android-এ অনেক সময় নোটিফিকেশন আকারে আসে, ট্যাপ করলে খোলে।
- **মেয়াদ শেষে MikroTik-এ ইউজার disable করবেন না** (PPPoE secret disable বা profile দিয়ে কানেকশন কাটলে ইউজার অনলাইনেই থাকে না, তাই পপ-আপ যেতে পারে না)। বন্ধ করার কাজ এই সিস্টেমের `bill-expired` রুলই করে।
- পেমেন্ট নিলে ড্যাশবোর্ডে নতুন CSV আপলোড করুন; পরের সিঙ্কেই ইউজার মুক্ত হয়ে যাবে। পরে এটা সরাসরি আপনার ISP billing সিস্টেমের ডাটাবেস থেকে নেওয়া যাবে।
- মেয়াদ ধরা হয় পেমেন্টের তারিখ থেকে। কেউ দেরিতে পেমেন্ট করলে তার তারিখ সরে যাবে।
- CSV-তে নেই এমন ইউজারকে এই সিস্টেম ছোঁয় না।
