পপ-আপ প্রিভিউ

গ্রাহক যেটা দেখবে।

সতর্কতা পপ-আপ · মেয়াদ শেষ পপ-আপ

সংযোগ

পাবলিক IP (বা ডোমেইন; লোকাল নেটওয়ার্কে থাকলে লোকাল IP), API পোর্ট, ইউজার ও পাসওয়ার্ড দিন।

MikroTik-এ API ইউজার বানান

Terminal-এ (সফটওয়্যারের IP বসান):

/user group add name=notifier policy=api,read,write,test
/user add name=notifier group=notifier password=পাসওয়ার্ড address=সফটওয়্যারের-IP
/ip service set api disabled=no port=8728 address=সফটওয়্যারের-IP
শুধু অনলাইন ইউজার দেখতে read যথেষ্ট; পপ-আপ পাঠাতে address-list লিখতে হয় বলে write-ও লাগে। API পোর্ট ইন্টারনেটে খুললে অবশ্যই address= দিয়ে সীমাবদ্ধ করুন।

ঠিকানা

ডোমেইন, MikroTik পাবলিক IP ও এই PC-র লোকাল IP দিন।

অ্যাক্সেস ঠিকানা

ডোমেইন চালু করার ধাপ

১) DNS-এ A রেকর্ড: ডোমেইন → MikroTik পাবলিক IP। ২) MikroTik-এ ফরওয়ার্ড রুল। ৩) PC-তে Caddy (ফ্রি HTTPS)। পাবলিক IP আসল হতে হবে (CGNAT চলবে না)।
